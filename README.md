# 💰 Pricess Money — أسعار المعادن والعملات الحية

> منصة ويب **مجانية وقابلة للتثبيت (PWA)** تعرض أسعاراً لحظية تُحدَّث كل 30 ثانية للمعادن النفيسة والأصول الرقمية وأكثر من 40 عملة عالمية وعربية مقابل الدولار — مع حاسبة مجوهرات، تنبيهات أسعار، مخططات تاريخية، ومقارنة أسعار البنك المركزي المصري.

**مبنى بـ HTML5 + CSS3 + JavaScript خام (ES Modules) فقط — صفر صُجَم، صفر مكتبات، صفر build tools.**

---

## ✨ المزايا

| الشاشة | ماذا تفعل |
|---|---|
| 🏠 **الأسعار** | شريط صرف أفقي (1 USD → كل عملة) + بطاقة لكل معدن (سعر الأونصة بالدولار + جدول سعر الجرم لكل عملة) + تفصيل عيارات الذهب 24/22/21/18 + شارة «مباشر» نابضة و chip زمن الاستجابة الملوّن |
| 🔁 **المحوّل** | مصدر واحد (أي معدن أو عملة) → نتائج فورية لكل العملات الظاهرة + قوالب سريعة 1oz / 1g / 10g / 100g + تبديل أونصة/جرام |
| 💎 **المجوهرات** | وزن + عيار + مصنعية/جرام + ضريبة 14% قابلة للإيقاف + **خصم المبشَّت بسعر السوق بعياره** → تفصيل 6 أسطر يعاد حسابه لحظياً |
| 🔔 **التنبيهات** | تنبيه سعر الجرم (فوق / تحت) بأي عملة + فرز الأقرب للتفعيل + إعادة تسليح تلقائية + إشعار داخل التطبيق مع جرس خفيف |
| 📈 **المخططات** | رسم SVG يدوي بلا مكتبات: hover tooltip + تنقل بالكيبورد + أنيميشن إدخال + إحصاءات (التغير/الأعلى/الأدنى) لفترات أسبوع → سنة |
| ⏳ **آلة الزمن** | قيمة أي وزن ذهب بين 2015 واليوم بأي عملة + نسبة النمو — بمنطق شفاف وموثق (انظر أدناه) |
| 🏦 **CBE** | سعر البنك المركزي المصري **الرسمي مقابل السوق الحي** مع الفرق والفرق النسبي ملونين |
| ⚙️ **الإعدادات** | لغة (عربي RTL / إنجليزي LTR) فورية، 3 أوضاع مظهر، اختيار من 51 عملة (بحث/فلاتر/بريسات/حماية)، اختيار الأصول، مسح التفضيلات |

### تفاعلات UI احترافية
Ripple عند اللمس · عدّاد أرقام متحرك (count-up) · وميض أخضر/أحمر باتجاه تغير السعر · Skeleton shimmer · Toasts متكدسة · نسخ أي قيمة بنقرة · أهداف لمس ≥44px · تنقل كيبورد كامل + Skip link · كل الحركات تحترم `prefers-reduced-motion`.

## 🚀 التشغيل

الموقع **ملفات ثابتة فقط** — أي سيرفر HTTP بسيط يكفي:

```bash
# من جذر المشروع
python -m http.server 8080 --bind 127.0.0.1
# ثم افتح http://127.0.0.1:8080
```

> ⚠️ ES Modules لا تعمل عبر `file://` — لازم سيرفر HTTP (أي واحد: `python`، `npx serve`، Live Server…).

### للنشر
ارفع الريبو فعلاً كما هو؛ أو GitHub Pages / Netlify / Cloudflare Pages — **لا build خطوة**. بعد النشر على HTTPS يعمل:
- التثبيت كتطبيق (PWA standalone) مع Shortcut سريعة
- التشغيل أوفلاين بالكامل بآخر أسعار متاحة (Service Worker + لقطة كاش)

```
├── css/
│   ├── tokens.css              # Design tokens: 3 سمات (داكن/فاتح/نظام) بمتغيرات CSS
│   ├── base.css · layout.css   # أساسيات + bottom bar ↔ sidebar
│   ├── components.css          # بطاقات/سكيلتون/توست/بانرات
│   └── features.css            # كل مكونات الشاشات + التفاعلات
└── js/
    ├── main.js                 # نقطة الإقلاع: store → i18n/SEO → polling → router → SW
    ├── store.js                # 🧠 Pub/Sub مركزي (بديل Zustand) + تفضيلات محفوظة
    ├── router.js               # Hash router: 9 مسارات + cleanup() لكل صفحة
    ├── pools.js                # مصدر الحقيقة الوحيد: 7 أصول + 51 عملة + عيارات
    ├── money.js                # دالة التحويل النقية الوحيدة: convert(amount, from, to)
    ├── api.js                  # المصادر: timeout 10s + إعادة محاولة Backoff أُسّي
    ├── polling.js              # دورة 30s ذكية + قياس الاستجابة الحقيقي
    ├── cache.js · history.js   # SWR snapshot + سجل محلي لمخططات المعادن
    ├── alertsEngine.js         # محرك التنبيهات (hysteresis)
    ├── seo.js                  # meta لكل مسار + JSON-LD ثابت/ديناميكي
    ├── i18n.js · format.js     # قاموس ar/en + تنسيق أرقام en-US مع عزلات LRI/PDI
    ├── ui.js                   # DOM helper + toast + count-up + ripple + beep
    └── pages/                  # home · converter · jewelry · alerts · chart
                                # timemachine · cbe · settings · more
```

### القواعد الذهبية في الكود
1. كل الأرقام تُخزَّن `en-US`، وأي رقم/كود لاتيني داخل نص RTL يُعزل بـ Unicode (LRI…PDI) — لا concat نصي في سياق RTL أبداً.
2. كل تحويل عملة يمر من `convert()` فقط، وكل حساب جرام يمر من `pricePerGramUSD()` فقط.
3. كل الحالة تعبر Store المركزي (Pub/Sub) — الصفحات لا تلمس بعضها.
4. لا stack traces للمستخدم — بانر ودّي + زر إعادة محاولة.
5. مفاتيح التخزين كلها مضمنة بالنسخة: `prefs_v2` · `price_snapshot_v2` · `history_v1` · `alerts_v3`.

## 🔌 مصادر البيانات (بدون أي API keys)

| المصدر | الاستخدام |
|---|---|
| `api.gold-api.com/price/{SYMBOL}` | الذهب/فضة/بلاتين/بالاديوم/نحاس (بالرطل)/BTC/ETH — بالدولار لكل وحدة أصلية |
| `api.frankfurter.dev/v2/rates` | أسعار الصرف اللحظية (مع fallback إلى `/v1/latest`) |
| `api.frankfurter.dev/v1/{start}..{end}` | التاريخ التاريخي للعملات |
| `api.frankfurter.dev/v2/providers/cbe/rates` | الأسعار الرسمية للبنك المركزي المصري |

**مرونة المصادر:** فشل رمز واحد لا يُسقط البقية (`Promise.allSettled`)، وفي غياب التاريخ لبعض العملات (EGP والخليجية غير متاحة تاريخياً لدى Frankfurter) يسقط الموقع على منطق شفاف وموثق: العملات المربوطة بالدولار (سعر ثابت تاريخياً)، ومراسي معروفة (متوسط ذهب 2015 ≈ $1,160/أونصة، EGP 2015 = 7.83)، وسجل محلي يتجمّع أثناء الاستخدام (~نقطة كل 5 دقائق، سقف 1440).

## ♿ إمكانية الوصول والجودة

- ARIA في المواضع الحرجة: `aria-current` للتنقل، `aria-pressed` للرقائق، `aria-live` للتحديثات والتوست، `role` للجداول والمخطط
- المخطط قابل للتنقل بالكيبورد بالكامل (نقاط focusable + tooltip)
- تباين عالٍ في السمات الثلاث، أهداف لمس ≥44px، حلقات تركيز ذهبية واضحة

## 🧪 الاختبار
اختُبر حياً على متصفح حقيقي: **9 مسارات × صفر أخطاء console**، والرياضيات متحققة مقابل المتجر الحي (ذهب $4,180.50/oz، EGP 53.375، رسمي CBE 53.5383، آلة الزمن +2358%). بيانات الأوفلاين والتنبيهات حُاكت وأُثبت سلوكها. التفصيل الكامل للبنية في [`architecture.json`](architecture.json).
